Gaura's Domain

These are my micro-CTFs to help absolute beginners start trying cybersecurity Capture The Flag challenges. They are very simple, so if you are already into this stuff, try out the Cryptopals CTF or OverTheWire or something.

Module 1

Caesar / ROT

Shift dial, Vigenère two-tone, Affine multiply & slide — 6 puzzles.
Module 2

Encoding

Decode-pipeline builder — base64, hex, URL, ROT13, Atbash — 9 puzzles.
Module 4

XOR

Demo + brute force + crib-the-key + same-key-twice boss. C4 (long key) outstanding.
Module 3

Hashing

Avalanche effect + MD5-vs-SHA-3 internals — Merkle–Damgård register view vs a real 3D Keccak state, step-through, real collision demo.
Bonus

Five Nights at Crypto's

Haunted-house bonus track — file forensics on a commandline. Unlocks once Caesar, Encoding and XOR are all finished.
