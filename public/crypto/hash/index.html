measuring this browser's real hashing speed…
Measured by timing this page's own JavaScript MD5 / Keccak with the animation's tracing switched off. Native and hardware implementations are faster still, so treat these as an upper bound on how long a real hash takes — the point is the order of magnitude. These two numbers are not a fair race between the algorithms. SHA-3 does its maths on 64-bit chunks, which JavaScript can only fake with a slow number type, while MD5's 32-bit chunks run at full speed here — so our SHA-3 is held back far more than our MD5 is. In real optimised code the two are much closer than these numbers make them look.
