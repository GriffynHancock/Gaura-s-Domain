Everything in a computer is ultimately encoded in bits (1s and 0s), which is a binary number system where, instead of ones, tens, hundreds and thousands, it has 20 (1), 21 (2), 22 (4), 23 (8), and so on. So while 6 is just 6 in our base-10 counting system, in binary 6 can be written as 0110, which means “no 8, yes 4, yes 2, no 1”.

ℹ Binary has an interesting property: you can combine binary strings using simple logic to “mix” them, and as long as you know one of the original strings, they can be unmixed. This is done through an Exclusive Or operation, where every bit of the two strings is compared to each other. The rule is: if two bits are the same, output 0; if different, output 1. This can be used to “lock” messages by repeating an XOR operation over and over, using a little string repeatedly across a big string.

XOR (⊕) takes two bits and outputs a 1 only when they differ, outputting a 0 when they are the same. Tap the bits below and see how they combine in an XOR operation.

A letter is just 8 bits, and those 8 bits are written in hexadecimal to save space — that's why the scrambled messages on this page show up as hex rather than long runs of 1s and 0s.
