## Module 2 — Encoding/Base64 (done)
4 puzzles, flat warm skin, click-to-build decode pipeline (Base64/Hex/ROT13 tiles → chips; empty = raw),
preview **TEXT ⇄ IMAGE** toggle (resizable), type-the-flag SUBMIT, solved-tick, dark mode, COPY output.
Decoders never throw → wrong method = nonsense text or **scrambled pixels** (IMAGE view always paints bytes
as RGB), never an error. No "check output" helper button (removed per user — they type + submit).
- I `flag{base64_is_not_secret}` (base64→text) · II `flag{wow!}` (base64→image bitmap) ·
  III `flag{hidden_in_the_bytes}` (imposter image + hidden flag in raw text; synth sting once) ·
  IV `flag{peel_the_layers}` (base64→hex; wrong order just gives nonsense; CyberChef copy-blob).
- Assets generated by `tools/build_base64_assets.py` (Pillow renders the bitmap + imposter; stdlib builds the
